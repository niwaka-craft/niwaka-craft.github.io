# テキスト編集ガイド

サイト内の文章、料金、リンク、作品情報は、すべて `siteContent.ts` にまとめてある。

## 通常の文章や料金を変更する

`siteContent.ts` を開き、ダブルクォート `"..."` の内側だけを書き換える。

例：

```ts
price: "¥100,000〜",
```

を次のように変更する。

```ts
price: "¥150,000〜",
```

カンマ、コロン、括弧は削除しない。

## 制作依頼の受付を停止・再開する

`commission` 内の `status` にある `accepting` を変更する。

受付中：

```ts
accepting: true,
```

受付停止中：

```ts
accepting: false,
```

`false` にすると、依頼状況が「受付停止中」に変わり、Contactの案内文も停止中用に切り替わる。依頼メールボタンは押せなくなる。再開するときは `true` に戻す。

## 作品カテゴリー

各作品の `category` には、次のどれか一つを指定する。

- `"environment"`：背景
- `"prop"`：プロップ
- `"character"`：キャラクター

## 作品を追加する

`projects` 内にある既存作品の `{ ... }` 一式を複製し、作品名、分類、説明、画像、制作範囲、リンクなどを書き換える。画像ファイルは `public/images` に保存する。

編集後は公開処理が必要になる。内容だけを変更した段階では、公開中のサイトには反映されない。
